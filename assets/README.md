# Assets Directory

## Banner Image

Place your custom banner image in this directory as `banner.png`.

### Recommended Specifications

- **File name**: `banner.png` (or `banner.jpg`)
- **Dimensions**: 1200x400px (or similar 3:1 aspect ratio)
- **Format**: PNG (with transparency) or JPG
- **File size**: Keep under 500KB for fast loading

### Design Tips

Your banner should include:
- Prune logo/branding
- Tagline: "Adaptive Discovery Engine" or similar
- Color scheme: Primary (#2596be blue) and Secondary (#5621d5 violet)
- Clean, professional design

### How to Add Your Banner

1. Create your banner image (1200x400px recommended)
2. Save it as `banner.png` in this directory
3. The README.md will automatically display it

### Alternative: Host Externally

You can also host your banner elsewhere and update the README.md:

```markdown
![Prune Banner](https://your-domain.com/path/to/banner.png)
```

Or use GitHub's raw content URL:

```markdown
![Prune Banner](https://raw.githubusercontent.com/declanmiddleton/Prune/main/assets/banner.png)
```
